# ごみの出口シート

大阪府南部15自治体むけに、家庭ごみの出し先を1枚にまとめた印刷用ページです。
お住まいの市を選ぶと、その市のごみリーフレット・粗大ごみ申込などのQRコードに切り替わります。
**A4・たて・1ページ**で印刷できます。

対応エリア：大阪市／堺市／八尾市／松原市／藤井寺市／羽曳野市／柏原市／大阪狭山市／
富田林市／河内長野市／高石市／泉大津市／忠岡町／和泉市／岸和田市
（一部の市は準備中です）
