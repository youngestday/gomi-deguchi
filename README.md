# ごみの出口シート

大阪府南部15自治体むけに、家庭ごみの出し先を1枚にまとめた印刷用ページです。
お住まいの市を選ぶと、その市のごみリーフレット・粗大ごみ申込などのQRコードに切り替わります。
**A4・たて・1ページ**で印刷できます。

対応エリア：大阪市／堺市／八尾市／松原市／藤井寺市／羽曳野市／柏原市／大阪狭山市／
富田林市／河内長野市／高石市／泉大津市／忠岡町／和泉市／岸和田市
（一部の市は準備中です）

# 並べてBAカメラ（`ba-camera/`）

左にビフォー写真、右にカメラのライブ映像を並べて撮影し、ビフォーアフター画像を1枚で保存するWebアプリです。

- ビフォーはその場で撮影、または写真ライブラリから選択
- 右側のカメラ映像にビフォーを半透明で重ねて構図を合わせられる（濃さを調整可能、オン・オフ切替）
- 0.5x（超広角）／1x のレンズ切替（対応端末のみ）
- 「BEFORE / AFTER」の文字を入れるか選べる
- 「保存・共有」から写真アプリに保存

カメラを使うため https で開く必要があります（GitHub Pages なら `…/ba-camera/`）。
